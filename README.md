# 呼叫家護師研討會報名網站

Public static website for the 2026 homecare seminar.

The website assets are in `site/`. GitHub Actions publishes only that directory to GitHub Pages.

Registration is currently unavailable. The public API configuration is intentionally empty, and the submission button stays disabled until an authorized service explicitly reports readiness.

Do not commit credentials, backend code, registration records, or private project files.
